Código de 2FA

Abre Google Authenticator (o la app que usas), busca «Mega Rifa Fusa» y escribe el código de 6 dígitos.

¿Primera vez? Activar 2FA

Supabase lo activa desde Perfil → Multi-Factor. Si no lo tienes aún, inicia sesión aquí, abre el panel, y aparece la opción. También lo puedes activar en tu perfil de Supabase.
